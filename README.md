# Thinkova website

Next.js (App Router) · TypeScript (strict) · Tailwind CSS 3 · React Hook Form + Zod · Lucide.
An eight-week AI course platform for Grades 5–8.

## Prerequisites

Node.js 20+ and npm 10+.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
